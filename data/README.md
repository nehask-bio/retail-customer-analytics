# Data

The raw data used in this project comes from the Olist Brazilian E-Commerce dataset.

The original CSV files are not included in this repository due to file size and to keep the repository lightweight.

The analysis uses the following core tables:

- olist_orders_dataset.csv
- olist_order_items_dataset.csv
- olist_customers_dataset.csv
- olist_products_dataset.csv
- product_category_name_translation.csv
